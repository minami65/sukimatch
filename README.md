# sukimatch

マッチングアプリ開発プロジェクト

## 概要

マッチングするアプリ

## ペルソナ

- 年齢層（25〜30歳男女）
- 目的（恋愛）
- 性格や悩み（マッチング疲れしてる、真面目な人に出会いたい）
- 使うシーン（通勤時、夜寝る前に軽く使う など）
-

## 技術スタック

- フロントエンド：React
- バックエンド：FastAPI
- DB:SQLite

## セットアップ方法

### バックエンド

- サーバー起動
  ```
  uvicorn app.main:app --reload
  ```

## 機能

- ユーザー一覧表示
- いいね機能
- マッチ判定
- マッチ一覧
- （余裕あれば）チャット
